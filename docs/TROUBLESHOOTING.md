# 故障排除

- **啟動回 PORT_ALREADY_IN_USE。** 核對監聽者。可在停止後更改隔離候選埠。未知程序保留原狀。
- **啟動回 WINDOWS_STORAGE_ACL_UNSAFE 或不安全路徑。** 選擇本機固定 NTFS 或私有 Unix 目錄。避開符號連結、硬連結、junction、雲端同步及網路磁碟。
- **憑證拒絕。** 核對本機 API 位址、有效期及 scope。撤銷、輪替和還原可能使前一份憑證失效。
- **UNKNOWN、STALE 或無法讀取駐留。** 檢查模式、節點身分與採樣時間。有效零值與空列表各有獨立語意。設備描述不會開啟實機派送。
- **工作一直排隊。** 在診斷頁核對資源鎖、別名與選擇原因。HOLD 也占用全域並行預算。工作擁有者可取消排隊中的模擬工作。
- **等待回 504。** 用 X-ACM-Job-Id 查詢工作。相同 Idempotency-Key 與內容應查回原工作。
- **資料庫缺失或不支援。** 檢查原件及 SQLite sidecars。以同代冷備份建立新的安裝位置，保留失敗副本。
- **安裝鎖殘留。** 先用 lock-status 核對。只有原程序已退出、鎖 SHA 與身分一致且另外存了完整備份，才可 recover-lock。資源 HOLD 仍保留。
